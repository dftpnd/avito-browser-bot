# Avito Browser Bot

Локальный бот на Rust для просмотра существующих объявлений и обнаружения новых. Работает через CDP в уже авторизованном Chromium. Принимает готовую ссылку поиска; собственные фильтры пока не реализованы.

## Браузер

Использовать **Snap Chromium** `/snap/bin/chromium`, профиль `/home/mg/kinobot/chrome-profile`, CDP `http://127.0.0.1:9222`. Сначала использовать работающий экземпляр. Бот проверяет параметры процесса и создаёт свою вкладку, которую закрывает при обычном завершении. Пользовательские вкладки и браузер не закрывает.

`/home/mg/kinobot` — отдельный проект. Здесь используется только уже авторизованная сессия Chromium с профилем по указанному пути. Проект Авито находится в `/home/mg/projects/avito`.

Если браузер ещё не запущен:

```sh
/snap/bin/chromium \
  --user-data-dir=/home/mg/kinobot/chrome-profile \
  --remote-debugging-address=127.0.0.1 \
  --remote-debugging-port=9222 \
  about:blank
```

Не запускать другой профиль и не перезапускать работающий браузер. Если нужен вход или проверка Авито, пройти её вручную. Бот не копирует профиль и cookies. При ошибке, капче или неожиданном перенаправлении текущий сбор останавливается без записи успешного сканирования.

## Запуск

Нужны Rust с поддержкой edition 2024 и работающий Chromium. Сборка SQLite включена в зависимости.

```sh
cargo build --release --locked
# Разовый сбор до трёх страниц готового поиска:
cargo run --release -- scan 'https://www.avito.ru/moskva?q=steam+deck' --pages 3
# Мониторинг каждые пять минут:
cargo run --release -- watch 'https://www.avito.ru/moskva?q=steam+deck' --pages 3 --interval 300
# Просмотр базы без подключения к браузеру:
cargo run --release -- list
cargo run --release -- report --output data/report.html
```

Поиск в примерах иллюстративный. Подставить свою ссылку. Параметры ссылки сохраняются, `p` заменяется номером страницы. Между страницами пауза 5 секунд; минимальный интервал мониторинга — 60 секунд после завершения прохода. Первый проход помечает все впервые увиденные в этом поиске объявления как новые. Повторные проходы возвращают только новые объявления и изменения цены в `changes`; строка JSON в stdout содержит также число просмотренных объявлений. Остановка — Ctrl+C, текущий проход завершается перед выходом.

База по умолчанию — `data/listings.sqlite`. Можно выбрать другую: `cargo run -- --database data/other.sqlite scan 'https://www.avito.ru/moskva?q=example'`. После успешного сканирования рядом с базой создаётся `report.html`. История изменений хранится в таблице `changes`, история проходов — в `scans`. Отчёт содержит все когда-либо сохранённые объявления; их актуальность на площадке не гарантируется. Исчезновение из выдачи не считается удалением.

Сбор ограничен указанным числом страниц. Бот читает только карточки поисковой выдачи, не открывает подробные страницы объявлений. Разметка Авито может измениться; её проверка на настоящем поиске нужна при первом запуске. Скорость появления в выдаче и доставки уведомлений Авито не гарантируется. Внешние уведомления и дополнительные фильтры — следующие этапы.

## Проверки

```sh
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
# Дополнительно: тест извлечения карточек в отдельной вкладке работающего Chromium:
cargo test --locked -- --ignored
```

Обычные тесты не требуют браузера или сети. Браузерный тест использует локальную HTML-фикстуру; объявления Авито не запрашивает.

## Устройство

Сценарии зависят от небольших интерфейсов `ListingSource` и `ListingRepository`. Домен проверяет объявления и ссылки. CDP, разметка Авито, SQLite и HTML изолированы в адаптерах. Подробности GRASP/SOLID и границы дальнейшего развития описаны в [docs/architecture.md](docs/architecture.md).

## Локальные данные

`data/`, выгрузки `avito-export*/`, архивы, личные настройки и профили исключены из Git. Исходные локальные инструкции и описание прежней выгрузки сохранены в `README.local.md`, этот файл не публикуется. Старые выгрузки и `export_avito.py` сохраняются на месте, бот их не изменяет.
