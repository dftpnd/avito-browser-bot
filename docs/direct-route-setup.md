# Исключение Авито из dft-vpn

Пользователь выбрал исключение Авито с сохранением VPN для остальных сервисов. На машине работает Xray с прозрачным перехватом; его конфигурация и nftables требуют root. `sudo -n` недоступен, а pkexec сообщил об отсутствии агента авторизации. Из сессии агента изменение не применено.

Подготовлен `scripts/configure_avito_direct.py`. Он не показывает конфигурацию VPN и ключи. При распознанной конфигурации добавляет первое доменное правило только для avito.ru, avito.st, avito.com (включая поддомены) и отдельный прямой outbound freedom без перенаправления. Это выход из локального маршрутизатора непосредственно к площадке, без VPN-туннеля. Другие назначения продолжают использовать существующие правила.

Правило использует [маршрутизацию Xray](https://xtls.github.io/en/config/routing.html) и [прямой outbound freedom](https://xtls.github.io/en/config/outbounds/freedom.html). Для прозрачного перехвата требуется уже включённое HTTP/TLS/QUIC sniffing; при отсутствии скрипт останавливается без изменений. Пользовательское routing.script также требует отдельной проверки и не изменяется автоматически.

Сначала посмотреть код и выполнить безопасную проверку в своём терминале:

```sh
cd /home/mg/projects/avito
sudo python3 scripts/configure_avito_direct.py --inspect
```

После проверки применить:

```sh
sudo python3 scripts/configure_avito_direct.py --apply
```

Скрипт проверяет новый конфиг через `xray run -test`, создаёт root-only резервную копию рядом с конфигом, устанавливает root-owned помощник и drop-in для проверки при рестарте VPN, заменяет конфиг с сохранением владельца/прав и перезапускает dft-vpn. Во время рестарта возможен короткий перерыв VPN. При ошибке применения восстанавливает исходный конфиг, удаляет свой drop-in и пытается вернуть сервис.

`/run/avito-direct-route.json` — публичные метаданные проверки (не ключи): домены, invocation/PID сервиса, время и хеш конфига. Это подтверждение конфигурации маршрутизации, не замена проверке фактических соединений браузера. После применения нужен дополнительный контроль маршрута на этой машине; текущий бот продолжает консервативно останавливать Авито до завершения этой проверки. Ключи или полный конфиг VPN в чат присылать не нужно. Если inspect откажется от применения, достаточно текста ошибки.

Исходные JSON-архивы Авито, профиль браузера и настройки остальных сервисов скрипт не переносит. Системный VPN глобально не отключается.
