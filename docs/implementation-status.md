# Текущее состояние реализации

## Работает

- Telegram-команды и постоянные кнопки статистики для одного владельца.
- Одна задача покупки, версии структурированных требований, изменение текстом через DeepSeek и подтверждение черновика.
- Проверка обязательных правил кодом; неизвестное подтверждение не даёт совпадения, Server Edition исключается по соответствующему правилу.
- Импорт всех доступных локальных диалогов, сообщений, наблюдаемых изменений и метаданных вложений. Повторный импорт не создаёт дубли. На локальном снимке: 605 диалогов, 6216 сообщений; 397 ссылок на вложения, без скачанных файлов.
- Резервное копирование и проверка SQLite. БД и конфиги имеют права 600 и исключены из Git.
- Загрузка описания найденной карточки через браузер при подтверждённом прямом маршруте.
- DeepSeek с проверкой цитат и происхождения фактов, кэшем и ограничением числа запросов. Проверка на искусственном описании Server Edition выполнена без передачи переписки.
- Оценки связанного диалога учитывают последние сообщения продавца и покупателя в пределах контекста; подтверждения принимаются от явно указанного продавца.
- Сохранение черновика вопросов с версией требований и снимком истории; устаревший черновик инвалидируется после изменения БД.
- События возникновения/утраты совпадений и сохраняемая очередь доставки в Telegram.
- Просмотр сохранённой истории в Telegram с эвристическим скрытием контактов и данных доступа.
- Проверка маршрута до сетевой навигации, консервативная остановка при неподтверждённой политике маршрутизации.

## Реализовано на следующем этапе, проверено локально

- Порты чтения диалогов, каталога и отправки; адаптер нативного клиента существующей страницы.
- Сохраняемая очередь и общий временной бюджет; постраничный сбор запросов и карточек.
- Полная и инкрементальная синхронизация истории, повторная обработка связанных предложений.
- Условная отправка после свежей проверки истории, отмена устаревших черновиков, контроль одного writer и неизвестных результатов.
- Открытие диалога по объявлению без отправки текста; автоматическая связь при однозначной идентификации участников.
- Скачивание доступных вложений с разрешённых доменов, SHA-256 и локальной фиксацией результата; приватные/устаревшие URL явно помечаются недоступными.

Подробные ограничения: [синхронизация и уточнения](sync-and-outreach.md). Эти функции ещё не проверены живыми запросами Авито из-за сетевой паузы.

## Требует продолжения

- Проверка исключения Авито из системного dft-vpn: его настройки и правила требуют прав администратора. Подготовлен проверяемый установщик `scripts/configure_avito_direct.py`; инструкция в `docs/direct-route-setup.md`. До применения и проверки живые запросы Авито остановлены.
- Живой сбор подробных карточек и сверка с текущей разметкой Авито на реальном поиске.
- Живая проверка реализованной сохраняемой очереди запросов, карточек, чатов и отправок на реальном аккаунте.
- Проверка адаптера нативного мессенджера на настоящих ответах; поддержка приватных вложений с сессионным доступом.
- Сверка автоматического связывания предложений и собеседников на реальных данных, разрешение неоднозначных случаев.
- Живой прогон реализованной последовательной отправки; до прямого маршрута настоящие отправки не выполнялись.
- Предложенные подробные разрезы статистики, открытие каждого счётчика, отметка просмотра уведомления, inline-ссылки на диалог.
- Денежный бюджет DeepSeek, многозадачность и расширенная проверка магазинов.
- Уточнение модели/Max-Q, бюджета, города, срока и допустимой предоплаты для реального поиска.

Этапы выпускаются отдельно; этот документ отличает работающие функции от запланированных и непроверенных на живой площадке.
